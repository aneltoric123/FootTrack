Z informacijskim sistemom FootTrack bomo podprli spremljanje rezultatov in statistike nogometnih tekem in tekmovanj.

Sistem bo omogočal prikaz rezultatov tekem(koliko golov je zadela domača/gostujoča ekipa) in vseh dogajanj na tekmi,ustvarjanje profilov in določanje najljubše ekipe ter tekmovanja katera uporabnik bi rad spremljal največ(npr. vsa tekmovanja ki se izvajajo v Sloveniji).Uporabniki bodo tudi lahko videli vse podatke o ekipah,igralcih,trenerjih,sodnikih,stadionih,prikaz vseh dogodkov na določeni tekmi ter vpogled v zgodovino pozameznih sezon tekmovanj,lestivco,točke posameznih tekmovanj(koliko zmag,remijev,porazov,golov ima posamezna ekipa) ter vpogled v prihodne tekme ter  še podatke o vsakem krogu tekmovanja.Obstaja tudi Admin ki lahko pregleda vse uporabnike in jih lahko izbriše če so sumljivi.Admin tudi lahko doda nove tekme,doda vse potrebne podatke in se nova tekma ustvari.
